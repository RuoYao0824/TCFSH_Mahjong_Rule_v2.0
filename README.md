### 簡述:
- 持點25000返點30000，一發裏寶槓寶有效的ありあり東南戰，負點續行  
- 三赤
- 有切上滿貫  
- 無途中流局  
- 尾親強制續行  
- 有Top賞，順位馬30/10  
- 錯和扣20pt
---
### 勘誤:
\item[25] 半莊的準備  
    \begin{itemize}  
        \item[(1)] 四名對局者任意就座。任意一人將「東·南·西·北」4張牌與筒子「1・2」2張牌,共計6張牌蓋著搓洗打亂,並排成橫向一列  
        \item[(2)] 排牌者的對家擲骰子。  
        \item[(3)] 將排好的6張牌翻開,將數牌移動到邊緣  
        \begin{figure}[H]  
        \includegraphics[width=0.5\textwidth]{抓位.png}  
        \end{figure}  
        \item[(4)] 自前述第2項出目所指定的席位之人開始,依逆時針方向拿取風牌。若此時點數為奇數,從「1」的那端開始拿;若為偶數,從「2」的那端開始拿  
        \item[(5)] 抽到「東」的人坐原本位置,此位置稱為假東。此後,每人各自坐到抽到風牌的對應席位  
        \item[(6)] 假東者擲骰子點數指定的席位者為起家  
    \end{itemize}
